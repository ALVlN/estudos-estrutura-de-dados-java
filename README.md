# 📚 Estrutura de Dados em Java

Repositório voltado ao estudo, prática e implementação dos conceitos fundamentais da disciplina de **Estrutura de Dados**, utilizando a linguagem **Java** e a IDE **IntelliJ IDEA**.

## 📌 Conteúdos do Repositório

* **Listas:** Listas Simplesmente Encadeadas, Duplamente Encadeadas e Circulares.
* **Pilhas e Filas:** Implementações estáticas e dinâmicas (LIFO e FIFO).
* **Algoritmos de Ordenação:** Bubble Sort, Selection Sort, Insertion Sort, Merge Sort e Quick Sort.

## 🛠️ Tecnologias e Ferramentas

* **Linguagem:** Java (JDK 17+)
* **IDE:** IntelliJ IDEA
* **Controle de Versão:** Git / GitHub
